歷經了發散式的學員進 web camp 之後，發現了過去曾經自學的人，對於進 web camp 學習會比較容易對這個環境上手。

![](/images/3301fc24-WRbP7Dt.png)

接下來，就以此為方向，進行招生。

## 做自己的生命設計師

我把要來面試的人，設定成「是在人生迷途，在人生的十字路口中徘徊的人」  
對於接下來要去哪，並沒有方向。

這樣的人來面試，其實是佔最大多數，他們不見得適合寫程式，也不見得喜歡 web ，但是對這樣的人生困境的人來說，只要是機會都要去看看。(尤其又是免費的)

所以，除了讓這樣的人了解自己並不適合來好想之外，我也想透過幾個問題，讓對方對於自己人生(職涯)的探索有更好的刺激與反思。

![](/images/3301fc24-GMuQMEi.png)

在 2018 年，我在 HPX 台南讀書會參加了一場《做自己的生命設計師》的書聚，作者是一位設計師，透過 Design Thinking 的方法，探索人生的未知，並且找到更適合的方法。就在 2019 年的過年前，我再把這本書看過一次，將書裡的方法與問題搜集起來。思考著未來人生新的可能性，思考著過去人生精彩的點點滴滴，將過往去蕪存菁，萃取讓自己正向的要素，成為探索未來人生的羅盤，成為你職涯發展的方向。

## 打造人生的原型

「如果你想成為 ooo，你就先把自己當作是 ooo」

書中提到一個設計的技巧，就是打造原型。原型可以讓設計者「取得足以解決問題的經驗」讓自己準備到更能解決問題的狀態。打造人生的原型，要解決的最大問題是「我適合做 XXX (某個職業) 」嗎？

如果你想賣咖啡，千萬不要頂下一間店，也不要馬上租個店面，而是要試試看咖啡餐車，到處跑解決咖啡豆的原物料與煮豆，萃取出咖啡後賣給客人的流程，當你解決這一切的問題，這個過程讓你可以用低成本體驗你的目標。

如果你想學 web 技術，也是一樣，可以先利用下班/週末的時間，買個[不錯的線上課程 (才幾百元)](https://lidemy.com/) 或者先看幾個不錯的 youtube 看看 web 技術的介紹或教學。再試著自己做一個你現在看見的頁面，做一個長得一樣的，看你能不能排出一樣的畫面，並且 RWD 還可以一模一樣。(但是不可以使用自己不熟的語法)

## 不是要看你的技術多強

因為我們並不是求職面試，所以面談之中，並不是要看你的技術多強。  
在這個時候的招生設計中，只要你有提及「有自學經驗」還是會問一些技術型的問題

「inline 和 block 差在哪？」  
「`===` 和 `==` 差在哪？」

是我的口袋問題 (不過現在不在面試時問了！會在招生演進過程解釋)  
多半都只是想了解你面對問題時，你的學習習慣如何？是不是會挖深？

問了問題，面試者多半是答不出來的，而且會覺得自己表現得很差，失去信心。(這是正常的)  
因為如果你都會，你也不需要來 training ，不是嗎？

### 因為閉包面進來的面試者

印象深刻的是，有一次我面試時，有問一些技術型的問題。

就問了口袋問題，不會  
問了基本的程式語言問題，不熟或忘了。

我就問他「那你最近一次學了什麼？距離現在多久？」  
『閉包！前兩週學的」  
「那你現在記得嗎？」  
『應該吧？』(依舊懷疑自己)  
「上來寫一下吧」(寫白板)

當次的面試，我一邊解工作的 bug 一邊面試 (客戶在燒 QQ 請原諒我)  
他寫完坐回來，bug 也解得差不多了，然後我轉頭看了一下

「哦！你寫得沒錯，你知道閉包有什麼作用嗎？」  
『隔離全域變數』(用懷疑的口氣說出來)  
「很好哦」

在面試完之後，其實還有出題目給他回去，用回信的方式再繼續觀察他的學習習慣與方法，是不是適合來好想學習。之後表現得很好，所以就進來當學員了。
