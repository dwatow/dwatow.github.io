在好想學習前，我有幾次和 web 相關的經驗

  1. 高中電腦課做過 HTML 的網站。
  2. 高中架設一個日本女子美聲團體(kiroro)的網站，當時可是亞洲最大
    • 全日本最舒服的聲音~kiroro
  3. 研究所剛考上時，接了一個案子
    • 南藝風華南台灣高雄地區傳統表演藝術數位網站建置計畫

以上，沒了。

而且單純的使用 HTML/CSS 而已。而且高中的時候 CSS1 才剛發明，當時的 border: dashed 可以說是超夯的語法。還有 opacity: .6 也是很常出現在網站上。

¶第一個問的技術問題

在切第 3 個版的時候，才開始找人問問題。那時問了一個用 position 解決掉的問題。

我自己的個性較怕生，不熟的人不太容易問問題。當時新生要有相當大的動力，才會找得到資源解決問題。

有 web 的問題，我第一個也是問 Howard。然後他會找人來幫我了解問題

¶如何提高自己的 training 效率

以鳳凰專案的三步工作法

  • 建立快速的工作流
    • 工作順暢
    • 公司與客戶的銜接
  • 回饋循環
    • 從源頭解決問題
    • 避免重工
    • 根除計畫外工作的來源
  • 建立文化
    • 鼓勵探索，吸取教訓
    • 迗代與練習是精通工作的先決條件

來 training 一開始就是摸索如何把任務完成。
再來才是自學可以順利的找到任務不熟悉的部份，避免重複學習，再將這些學好，再完成任務
最後，讓所有的人都這樣子，並且試著找到更有效率的方式來進行自學與完成任務。

¶現在學的，是學長姐工作時，會使用的技術嗎？

我記得我學切版學到 Sass 時，我問學姐「這是你接案時會使用的技術嗎？」，他說「是呀」我就知道我自己的學習之路，似乎足夠了。

其實，這幾個月以來，從 CSS 語法的用法，到產生 CSS 語法的工具，甚至之後有學 JavaScript 到框架時，所學的方法或思考方式，是不是第一線上戰場會適用的觀念或技術，會影響我自己對於學習這件事決定要深要廣，還是要不要調整，都是可以參考的地方。

¶如何在好想要學得順利

找對隔壁的人，坐在隔壁的人如果可以幫你秒解問題，你的學習之路會就順利許多。

要問問題時，有一半想要自己研究出來，有另一半想要找人一起討論，這兩者之間的選擇，每天都在掙扎。自己學得好，別人會來找你，你也可以去找可靠的人。

在我學切版時，很幸運的有一個讀書會認識的朋友。他切版七年左右。有這樣的伙伴一起討論問題，沒有他切不出來的版，沒有他解決不了的切版問題。所以，我喜歡他坐在我旁邊可以問問題。

¶遇到 AMOS 改變了我對學習 CSS 這件事

過去，我的確就是 Google 學 CSS。學一個查一個，這不是問題。
但是這樣累積了不少的問題。

但是，有一次 AMOS 來好想工作室開課。我也報名他的課程，在這過程除了學 CSS3 之外，最主要的是問了很多基本的觀念問題。

我們來驗證!!

看見了 AMOS 在上課時，總是會說「我們來驗證」「我們來驗證」「我們來驗證」「我們來驗證」「我們來驗證」「我們來驗證」…。

沒有把 inline 和 block 弄清楚

在我學了半年時，我問一個問題

vertical-align 用在什麼地方？

我記得那時 AMOS 跟我說「我覺得你沒有把 inline 和 block 弄清楚」，讓我自己覺得，我確實學習得不夠清楚。所以，與 AMOS 相遇，確實是改變了我學習 CSS 找到了一條正確的道路！要有「驗證精神」
