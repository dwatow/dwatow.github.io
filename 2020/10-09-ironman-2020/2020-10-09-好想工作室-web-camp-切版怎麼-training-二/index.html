好想工作室 web camp 切版怎麼 training (二)

  1. 避開市場假象
  2. 用「類家庭教育」取代填鴨式教育

在前一篇，介紹了使用 code review 的方式進行互評。讓每個學員之間有充份的交流，並且在交流之後再做一次練習，讓別人的經驗與建議，再經過一次的實作，化為自己的經驗。

來整理一下重點

  • 與人交流，互通有無
  • 充份練習，增加經驗

這是每個不管用什麼管道學 web 都應該要具備的條件。畢竟，前端技術就是很多很多的鋩角的知識組合體。不靠交流有些知識是你想都想不到。

但是，光是這樣是無法有效率的學習的。
因為「錯誤的觀念，會讓你的練習多花力氣。」

和很多運動一樣，如果動作不正確，姿勢不對，練習再多不只是不會讓你進步，還會為了嬌正花很多時間，最可怕的是會造成運動傷害。

很不巧的寫 code 也有異曲同工之妙。

¶避開市場假象

20170-02-17 我來好想工作室當學員，也是從切版開始學，歷經了半年之後，去上 AMOS 的 (CSS3) 課，並且問了 AMOS 問題後，AMOS 跟我說「我覺得你 inline 和 block 沒有搞懂」。

那一年的年底第一次參加鐵人賽，2017-12-11 開始的第一篇前端新手村 ，花費將近一年的時間，除了 CSS3 已經有上了老師的課之外，我覺得基本的切版觀念，光靠 Google 查詢，並口耳相傳各種技巧並練習，並無法滿足我。

我覺得這樣久而久之會形成市場假象，因為人類的斷判力，會在充份合理性的情況之下，失去作用，無法判別是否為真。正是因為有彼此交流，才容易造成這樣的錯誤方向，所以才有「尋找真相的渴望」。

市場假象:
由於人類語言中詞語的定義與這些詞語，所代表的自然界的真實事物之間不完全一致而產生的。

前端新手村就設定成「要寫的觀念，重新查一次 w3c 的文件看看，看可以讀懂多少」，變成了 30 天的 w3.org ，也讓我對於前端切版的基本觀念有了正確的建立。接下來的時間就是不斷的幫學員們 code review，把重複的問題一再複習。

但是那 30 天以來，每天查一篇，還有時間每天可以寫一篇鐵人文章，如果不是寫鐵人的話，那麼那個培養出來的學習習慣，帶來的學習深度與正確性，會在一開始就建立得很好。而且習慣閱讀英文，會觀念正確。

這不進步，才是反常。

¶用「類家庭教育」取代填鴨式教育

在 training camp 演化至此，我體會到了一件事。
所謂的自學，靠的是環境。人都是懶的，如果你可以取得知識而不花費太多的力氣，那麼自學才有可能成為成真。

Google 搜尋引擎對自學來說的重要性，在於「求真」變得省力了。但是人卻沒有改變「懶」這個本性。真正會把事情「做到位」的人，被稱為「有興趣」的人，久而久之學得起來就被稱為有興趣。但是，其實知識的取得，對每個人來說是平等的，只要你願意花力氣，願意去尋找，相信心中真正能說服你的原因，還沒有找到，那麼你就比較容易取得更真實的答案。(但是沒有標準答案)

唸書的時候，往往有許多同學有一些特殊長才，有些人特別會畫畫，有些人特別會對自己做造型，有些人特別會寫字…。這些只是因為，他們各自花時間取得知識並且練習，才展現出來的結果，被稱為「有興趣」。但是，只要你願意，人人能做到這件事，只是每個人會做自己覺得快樂的事。

在 training camp 我能做的，並不是教給學員最正確的知識，但是我必須告訴他們，如何走一條最有效率的道路學習，快速的經過人生的這段時光。雖然痛苦，但是這樣最省時間，只要你願意，取得的知識是最正確的，連我都不會的那種正確。所以，並不是我學會了，才教學員。是學員學會了，再告訴我他怎麼學的。

「我在家裡學到了一件事 就是教育家不見得要教書 而是給你環境和資源 激發你自學的本能 自主學習,自我探索 做自己的主人 都是良好教育下養成的美德」

這句讓我領悟「家庭教育，不同於當老師，而是靠環境和資源，觸動你想自學的熱情。」

許多成功的自學者，就是有辦法自己找到「判斷真假」加速自己對知識取得的正確性，縮短學習的時間。自學並不是叫人自己去學。而是建立一個環境，讓人在這輕鬆的取得特定的知識，還有人可以交流，有辦法可以判斷真假。這樣就是一個好的自學環境，不需要別人教，沒有進度壓力，每一個人回歸到工業革命之前的學習方式。
