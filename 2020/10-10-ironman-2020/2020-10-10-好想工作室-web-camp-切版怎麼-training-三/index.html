好想工作室 web camp 切版怎麼 training (三)

  1. 不安排破冰，會自然融冰
    1. 不管學到什麼技術，但改變了個性
  2. 意外的「知識管理」
    1. 和自己的 camp 一起成長

在前一篇，介紹了使用 code review 的方式進行互評。讓每個學員之間有充份的交流，並且在交流之後再做一次練習，讓別人的經驗與建議，再經過一次的實作，化為自己的經驗。並且，試圖找尋規範，拼湊出問題的真相，除了可以重現問題，還可以用簡單的幾個原理解釋大部份的都市傳說。

來整理一下重點

  • 與人交流，互通有無
  • 充份練習，增加經驗
  • 查找規範，萬宗歸一

一開始，學員只需要找我 code review，歷經了一屆學員之後，我發現問題都是重複的，常見的問題不外乎就是 Margin Collapse、inline 元素間、virtual-align、<img> 預設的 virtual-align: baseline (inline 的垂直置中問題) 會造成的迷樣的空白。而這些對我而言，一開始有被重點加強複習到。當這些常見的問題，變成我熟練的技術之後，對我而言這些複習就是浪費。

所以，我除了引入 code review 之外，還做另一件事，就是請學員找學員 code review。如果想獲得經驗值，可以當第一個或第二個 code review 的人，自然就會看見各種新手寫法囉。

¶不安排破冰，會自然融冰

前面有提到，我們的學員報到時間，並不是同一天。不同於學校的課程，也不同於大學營隊的經驗。那這個問題，我也一直沒有處理它，我想先處理重要的問題之後如果需要增進學員之間的熟悉度，再來處理。

所以，一開始我只是處理了前述的問題 code review 造成的經驗累積，一直在 mentor 身上，經驗累積久了就是做重複的事了，花費的時間並不能讓 camp 的人進步。

所以引入了學員幫學員 code review 之後，新學員在進行第一個切版任務時，會有許許多多的問題不敢找人討論，唯一比較認識的只是面試自己的學長姐，但是等到第一個版切完，就被迫帶著自己切好的版，一個一個找學長姐認識，並且請他們幫自己看版，除了給予一個充份的理由，接觸學長姐之外，還可以透過 code review 的時間(通常都會超過一小時)，一行一行的聊完自己的原始碼與想法，也了解學長姐給予的想法，可以更認識一位學長姐在 coding style 上在乎的點。

學長姐講的不見得是正確的。
不同的人講的，有時也會產生矛盾。
而這才是真實世界。

自然而然的，每個新生久了就不會怕生。若新生是內向者，大家都會認識他的個性，不會缺少應該有的交流。

¶不管學到什麼技術，但改變了個性

有一個學員，他原本寫後端的，前一份工作串金流串到太無聊了。所以跑來學前端，但是印象中，他的前端表現平平，與人交流也沒有特別多，是個超級內向的人。

找到工作之後，要回台北了，我問他「家裡的人，怎麼看待你來學前端這件事？」他說「其實，我媽並不在乎我學到什麼，但是他覺得我的個性改變了，變得比較常與人講話，也比較開朗，他覺得這一切就值得了」

沒想到我們的 camp 可以改變人的個性了。

¶意外的「知識管理」

對我來說，學員與學員之間開始看版，其實還有點寂寞，因為大部份的問題，他們都自己解決掉了。而輪不到我上場。(哈)

但是，當找到我的問題，確實都是一些不常見的問題，甚至出現了在不同瀏覽器中出現的行為不同的無定義問題(就是依照規範解釋，這問題是沒有定義的)，不過後來在規範中有修正了。

而 camp 中的每個學員，會彼此交流，也會看規範學習，這麼一來，還要 mentor 做什麼？哦！不對！是 mentor 除了閒下來之外，還有什麼好處呢？

先說說「閒下來這件事」其實就是獲得了更多的時間，不用為了 camp 的技術能力而準備，他們已經具備足以自主產生能量的條件了。

我能做的，就是兩件事

  1. 維護這個系統的順暢度
  2. 把關放進去的人是不是會破壞系統
  3. 反覆的觀察目前 training 的內容是不是適用於界業的需求

產出完全不用擔心。
但是，其實空下來的時間，就可以拿來做自己的工作。

¶和自己的 camp 一起成長

另外，還有一個好處就是跟著學員們成長。他們是很多個人一起追求知識的有機體，而我平常要做工作 (還好不至於要變碼農)，與這樣的 camp 相處，反而增加了一個學習的管道，可以繼續使用自己的學習習慣來問學員的學習過程，再吸收他們的經驗。

而且也不用擔心他們的平均水平會掉下來，因為只要把前述的幾件事把關好，在 camp 裡的知識，會透過交流去蕪存菁，將好用的技巧留下來。而且會透過規範判斷真假，將不正確的知識排除。剩下的，只要時間拉長，就可以愈來愈強了。
